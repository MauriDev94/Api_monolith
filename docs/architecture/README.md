# Architecture

Esta carpeta documenta las fronteras de módulo, las reglas de
dependencia y otras decisiones estructurales del proyecto.

Las reglas de Clean Architecture que aplican a este repo viven en
`AGENTS.md` (sección "Dirección de dependencias"). Este directorio
es para documentos de mayor nivel: cómo se compone un feature, qué
puede importar qué, qué convenciones siguen los bounded contexts.

Esta carpeta se crea **vacía a propósito**: la primera decisión
estructural que amerite su propio documento agregará el primer
archivo.
