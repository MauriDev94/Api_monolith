# Architecture Decision Records

Esta carpeta contiene los ADRs del proyecto, numerados secuencialmente
como `NNNN-slug.md`. Cada ADR registra una decisión arquitectónica,
el contexto que la motivó y las alternativas rechazadas.

Los ADRs no se editan una vez aceptados. Una decisión que cambia se
supersede con un ADR nuevo que referencia explícitamente al anterior.

Esta carpeta se crea **vacía a propósito**: el primer ADR nace cuando
hay una decisión que documentar, no antes. Un ADR-placeholder es
basura generada.
